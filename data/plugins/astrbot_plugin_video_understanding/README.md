# 视频分镜理解

在正常聊天中发送可公开访问的视频链接，或发送带下载地址的 QQ 视频附件。插件下载视频，沿完整时间线抽取九帧，拼成带格号和时间戳的一张图，使用当前识图模型生成画面描述，再交给普通聊天请求。聊天触发规则沿用既有配置。

支持 B站长链、b23 短链、YouTube、抖音、小红书、微博、腾讯视频、西瓜等域名，以及 HTTP/HTTPS 视频文件直链。网页解析由 yt-dlp 提供；站点要求登录、风控或不支持匿名下载时，会向当前请求标注视频未读取。插件不保存登录凭据。

## 安装与配置

在 AstrBot 的虚拟环境安装本目录 `requirements.txt`。FFmpeg 和 ffprobe 可来自 `ffmpeg-binaries`，也可放入本插件的 `tools/ffmpeg/bin/` 或加入 PATH。`tools/` 中的本机二进制不进 Git。

`_conf_schema.json` 的 `enabled` 默认开启。视觉模型复用 `provider_settings.default_image_caption_provider_id`；未指定时使用该会话的聊天模型。模型必须实际支持图片输入。

## 处理边界

- 一条消息最多处理一个视频，每台机器人同时处理一个任务。
- 视频不超过80 MiB、10分钟、4000万像素；网页视频选择不超过480像素的可用档位。
- 九格图片每格长边420像素，覆盖完整视频；离散帧无法呈现所有瞬间。
- 总处理预算100秒，下载45秒，视觉描述40秒；超时和失败会明确标注尚未读取。
- 只提供画面，不读取音轨。模型不能据此声称听过对白或音乐。
- 成功描述最多缓存64条、6小时，仅存本机进程内存。下载文件和帧在任务结束后清理；卸载等待任务和子进程结束。

正常日志包含启用状态、工具是否可用、完成状态及错误类型。外部工具错误保留退出码和经过 URL 脱敏的诊断，不记录视频内容。
