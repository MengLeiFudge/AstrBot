# 视频分镜理解

在正常聊天中发送可公开访问的视频链接，或发送 QQ 视频附件及含视频的合并转发。插件使用 [DSH Video Storyboard](https://github.com/SAOS-3624/dsh-video-storyboard) 扫描镜头变化，抽取代表帧，按切换密度排版分镜图。主聊天模型直接接收分镜原图、逐格时间清单及可用字幕。聊天触发规则沿用既有配置。

支持 B站长链、b23 短链、YouTube、X/Twitter、抖音、小红书、微博、腾讯视频、西瓜等域名，以及 HTTP/HTTPS 视频文件直链。网页解析由 yt-dlp 提供；登录限制或站点风控可能阻止下载，失败会在当前请求中标注实际原因。

## 安装与配置

在 AstrBot 的虚拟环境安装本目录 `requirements.txt`，并安装 Node.js 20 或更新版本。FFmpeg 和 ffprobe 来自 `ffmpeg-binaries`，也可放入本插件的 `tools/ffmpeg/bin/` 或加入 PATH。`tools/` 中的本机二进制不进 Git。分镜引擎源码随插件提供，无需安装 DSH 应用。

`_conf_schema.json` 的 `enabled` 默认开启。当前会话的主聊天模型必须支持图片输入。B站下载使用直连；X/Twitter和其他视频站点复用本机 HTTP/HTTPS 代理。X/Twitter使用公开帖子的嵌入信息解析视频，该接口可能不提供帖子的全部媒体或元数据。网页下载通过 curl_cffi 提供浏览器 TLS，并保持证书校验。

## 处理边界

- 每条消息最多处理一个视频，每台机器人同时处理一个任务。QQ 本机视频及合并转发通过公开 OneBot API 读取原消息，核对消息 ID、类型、原发送者及群 ID 后，使用结构化视频段中的下载地址或本机文件，路径不可读时按原视频文件标识调用 `get_file` 补下载；不从聊天正文读取磁盘文件。转发最多3层、64节点、4次查询和256个消息段。
- 视频不超过80 MiB、10分钟、4000万像素；网页视频选择不超过720像素的可用档位，并合并可用音轨。
- 使用 DSH `compact` 策略，最多4张图。分镜数量随画面变化决定，图片预算可能合并镜头；离散采样不能保证呈现所有瞬间。
- 总处理预算180秒，网页下载90秒，字幕取帧30秒、OCR子进程65秒，分镜子进程110秒；总预算先到时会结束整个进程树。
- 优先使用下载到的中英文站点字幕，其次使用容器内嵌字幕。没有字幕文件或字幕轨时，用 Windows 自带中文 OCR 每0.5秒读取视频画面，合并连续重复行，单独附上时间表；不用缩小后的分镜格子读取歌词。需要本机安装中文 OCR 语言资源。结果标注采样范围和实际完成状态，可能包含歌词、片名、水印及识别错字；不等于完整音频转写。
- 分镜原图最多缓存8项、24 MiB、1小时，仅存进程内存。OCR最多1200帧、55秒识别预算，文字时间表最多32000字符；达到限制时明确标记未完成。临时视频、字幕、采样帧和引擎状态在成功、失败或取消后清理，QQ原有视频缓存保持原样。卸载等待任务和子进程结束。

日志记录实际附给主模型的图片数、格数、视频时长，以及工具退出码和经过 URL 脱敏的错误。来源及许可证见 [vendor/NOTICE.md](vendor/NOTICE.md)。
